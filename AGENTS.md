# Agent rules

Follow `pa-context` for paths, privacy, and summary versus verbatim. Do not restate that file.

- Write only under `notes/`. Do not write notes into a team repo, PR, ticket, or chat destined for someone else.
- Do not invent people, quotes, dates, or a PIP. Leave unknown. A headcount is not a roster.
- Living pages update in place. Meetings, sources, and evidence append. Update the matching index.
- Exact words means quote the source file. If none exists, say so.
- This window only. Do not add the folder to another workspace.
