# Vault map

Privacy does not shrink this list. Every row stays in scope.

| Need | Skill | Where it lives | Summary | Verbatim |
|---|---|---|---|---|
| Meeting minutes and discussion | pa-meetings | notes/meetings/YYYY/ | Discussion, decisions, actions | Raw notes or a linked source |
| Direct reports and current work | pa-direct-reports | notes/people/direct-reports/ | Now, blockers, commitments | Linked 1-1 and sources |
| Manager, planning, focus | pa-manager | notes/people/manager/, notes/focus.md | Priorities and focus list | Linked manager-sync sources |
| Influencers, POs, architects | pa-stakeholders | notes/people/stakeholders/ | Controls and open asks | Linked conversation sources |
| Emails and exact quotes | pa-sources | notes/sources/YYYY/, notes/quotes.md | Abstract | ## Verbatim and quotes.md |
| Unofficial promotion cases | pa-promotion-case | notes/promotions/<slug>/ | case.md thesis | evidence.md rows plus sources |
| Performance concern / possible PIP | pa-performance-concern | notes/performance/<slug>/ | concern.md pattern | evidence.md timeline plus sources |
| Owned products vs named partner integrations | pa-portfolio | notes/portfolio/ | What the team owns vs the partner | Vendor notes and sources |
| Delivery cadence and impediments | pa-delivery | notes/delivery/ | Cycle goal and user-facing outcome | Review notes if pasted |
| Tracker lookup, if a tool is connected | pa-jira | chat, then person page only if asked | Open work summary | Keys, not a dump |
| Catalog drift | pa-integrity | report in chat | Missing rows and stale pages | Does not dump sources |
| Users of the team's products | pa-users | stakeholder pages plus portfolio | Workflow and broken means | Their words, quoted |
| Specific feedback, praise or corrective | pa-feedback | person file, append-only | What was said | Exact words if pasted |
| Coaching junior through senior architect | pa-coaching-span | person files | 1-1 agenda in chat | Only if user asks to save |
| Important dates and recurring cadence | pa-dates | notes/dates.md, notes/calendar.md | Next 7 days, overdue, usual events | Only if a source was filed |
| Organization hierarchy | pa-context | notes/org/INDEX.md | Named relationships | Filled only when the user dictates them |
| Catalog across all of the above | pa-context | notes/INDEX.md and the track indexes | Sweep and status | Paths to source files |

Inbox is the buffer when the user has not chosen a track yet. File from inbox into the table above. Do not leave durable facts only in inbox.
