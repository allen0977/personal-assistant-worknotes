# First start

Appendix. Field meanings live in [CONFIGURE.md](CONFIGURE.md). Use this file only if you already know the answers and want the short prompts. Do not keep a second copy of the questions here.

Run these in the `~/worknotes` window, in order. The agent should ask. It should not invent people, counts, partners, or an org chart.

Replace the angle brackets. Leave a line out if it does not apply. Do not paste the example block unless those facts are yours.

## 1. Contract

```text
This vault is ~/worknotes. Read pa-context, notes/MAP.md, and SHARE.md.
Facts about my team belong in notes/, not in skills.
Privacy limits where files live, not what I catalog.
Do not write outside notes/. Do not invent names, vendors, headcount, or a company ladder.
```

## 2. You

```text
Help me fill notes/me.md. Ask before you write.
I lead <function of the team>.
We serve <organization>.
Our users are <who>.
My delivery role is <Scrum Master / not Scrum Master / other>.
I have <N> direct reports, spanning <levels>.
```

## 3. Team shape

```text
Read notes/team.md and fill only what I confirm.
Partner integrations, if any: <names>. Ask which products we actually use.
Products we own end to end: <names, or none yet>.
Ask before you create product files.
```

## 4. Direct reports

```text
Add my direct reports one at a time. Ask for name, level, and what they own now.
If anyone is on an unofficial promotion track, I will name them. Do not assume a count.
If anyone is a performance concern, I will name them. Status stays concern until I say a PIP is open.
Do not put promotion evidence and concern evidence in the same file.
```

## 5. Organization stub

```text
Read notes/org/INDEX.md.
I will dictate the chart later. Until I do, leave people unknown.
Do not guess who reports to whom.
```

## 6. Dates

```text
Read pa-dates. Open notes/dates.md.
Ask me for 1-1 cadence, sprint boundaries, and any review or vendor window I already know.
Do not add promotion or concern dates unless I dictate them.
These only surface when I open this window or ask what is due.
```

## 7. One real sprint, if you run one

```text
If notes/team.md says I run a delivery cadence, open a cycle with pa-delivery.
Ask me for a goal a user would recognize, who must be in review, and one current impediment.
If I am not Scrum Master, skip this.
```

## 8. Check

```text
Sweep the vault. List what is still unknown.
Do not fill unknowns yourself.
If a skill contains a headcount, a partner name, or a person, say so. That fact belongs in notes/.
```

Configuration questions live in CONFIGURE.md. Do not store an example team.
