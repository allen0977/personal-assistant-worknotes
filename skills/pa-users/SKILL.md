# Users

Follow `pa-context`. Read `notes/team.md` for who the users are. If that field is unknown, ask. Do not assume a profession, a lab, or a partner.

1. Keep user words as stated. Do not translate them into a ticket unless the user asks.
2. A demo or adoption issue goes on the product row in `notes/portfolio/INDEX.md`, or a source file if they pasted exact words.
3. Do not treat user frustration as a performance fact about a direct report unless the user explicitly files it that way.
