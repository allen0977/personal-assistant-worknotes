# Manager

Follow `pa-context`. The user's manager is not a direct report and not a stakeholder.

1. Confirm the name and spelling. Follow the write protocol in `pa-context`. Copy `assets/manager.md`.
3. Update `notes/focus.md` only when the user states or accepts a focus change. Copy `assets/focus.md` if `notes/focus.md` is still the empty template and they accept a change.
4. An upward review with a director or VP is still `manager-sync`. Do not invent the person's name.
