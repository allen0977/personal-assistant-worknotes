# Feedback

Follow `pa-context`. This is not a performance case and not a promotion case.

1. Ask who, the date, and whether it was praise, corrective, or feedback the user received. If any of those is missing, ask. Do not infer tone.
2. Store the observable behavior and the effect the user stated. A compliment with no example stays thin. Say so.
3. Append under `## Feedback` on the person file. Do not rewrite older lines. If they pasted exact words, also file them with `pa-sources`.
4. Do not copy corrective feedback into `notes/performance/` unless the user says it belongs on the concern track.
5. Do not copy praise into a promotion case unless the user says it is evidence.
6. A draft of what to say stays in chat unless the user says to save it.
